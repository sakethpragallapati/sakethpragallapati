## 🚀 Projects

### [CURO AI](https://github.com/sakethpragallapati/CURO-AI) — Knowledge Graph-Enhanced Medical RAG
A GraphRAG system that doesn't just retrieve documents — it *reasons* over them. It traverses **30+ symptom-disease-treatment relationships per query** in Neo4j, cross-references the **474M+ work OpenAlex corpus** with a custom authority-scoring algorithm, and runs every answer through a **ChromaDB-based semantic firewall** with distance-thresholding to catch hallucinations before they reach the user.  
`Python · FastAPI · Neo4j · ChromaDB · LangChain · Groq (Llama 3.1)`

### [HydraSense](https://github.com/sakethpragallapati/HydraSense) — Hydration Prediction System
A 3-tier microservices app (React → Node.js API → Flask ML service) that predicts hydration status in real time. Benchmarked **8 ML algorithms** across 30,000 records before landing on LinearSVC, which hit **99.85% accuracy** — and shipped it with a GitHub Actions CI/CD pipeline for Dockerized deployment and continuous retraining.  
`React · Node.js · Flask · Docker · CI/CD`
