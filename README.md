## Featured Projects

### CURO AI — Knowledge Graph Enhanced Medical RAG

A healthcare-focused GraphRAG system that combines knowledge graphs, semantic retrieval, and large language models to generate evidence-based clinical insights.

- Built using Neo4j, ChromaDB, FastAPI, LangChain, and Llama 3.1.
- Integrated knowledge graph traversal with semantic retrieval for improved reasoning.
- Implemented hallucination mitigation techniques to enhance response reliability.

**Repository:**  
https://github.com/sakethpragallapati/CURO-AI

---

### HydraSense — Hydration Prediction System

An AI-powered hydration prediction platform that provides personalized recommendations using machine learning and environmental data.

- Developed with React, Node.js, Flask, Docker, and GitHub Actions.
- Integrated real-time weather data into prediction workflows.
- Automated deployment and model retraining through CI/CD pipelines.

**Repository:**  
https://github.com/sakethpragallapati/HydraSense

### UI/UX Recommendation System

An AI-driven platform that analyzes web interfaces and generates usability improvement recommendations.

- Utilized YOLOv8 and large language models for UI analysis.
- Automated detection of usability and accessibility issues.
- Generated actionable recommendations to improve user experience.
